<br/>

A crash-safe, resumable AI pipeline built for automated insurance damage claim verification, combining vision-based analysis with rule-based checks.

| Aspect | Details |
|---|---|
| **Stack** | Python, Google Gemini 1.5 Flash (Vision), Heuristic Rule Engine |
| **Scale** | Multi-stage pipeline processing image + metadata claims |
| **Performance** | Resume-capable execution to prevent pipeline failure loss |
| **Security** | Isolated processing stages with checkpointed state |
| **Impact** | Built for HackerRank Orchestrate (June 2026) national hackathon |
